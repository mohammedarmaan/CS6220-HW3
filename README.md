# CS 6220 HW3

## Files
- `HW3.ipynb`: k-NN (Q2–Q5), perceptron (Q6–Q8), single neuron (Q9)
- `requirements.txt`: dependencies

## Setup and run
```bash
python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
jupyter notebook HW3.ipynb          # Kernel -> Restart & Run All
jupyter notebook HW3.ipynb   # downloads MNIST on first run
```
Tested with Python 3.12, numpy 2.4, matplotlib 3.10, scikit-learn 1.8.
